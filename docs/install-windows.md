# Install on Windows

1. Download **[PhoneMistri-Helper-Setup.exe](https://github.com/h3llix/rms-release/releases/latest/download/PhoneMistri-Helper-Setup.exe)**.
2. Open it. Windows may show **"Windows protected your PC"** — the installer
   isn't code-signed yet. Click **More info → Run anyway**.
3. The installer finishes on its own. A PhoneMistri icon appears in the system
   tray (bottom-right, near the clock — check the **^** arrow if you don't see it).
4. Go back to PhoneMistri in your browser → **Settings → Printing & Documents**
   → choose **PhoneMistri Helper**.
5. The first time, your browser asks to let PhoneMistri connect to apps on this
   device. Click **Allow**.

Your printer should already be installed in Windows (it shows in
*Settings → Bluetooth & devices → Printers & scanners*). If it isn't, the
Helper's setup screen can add it for you.
